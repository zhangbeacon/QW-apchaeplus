# QW-Apache Plus

第九届"强网"拟态防御国际精英挑战赛 · 设计安全大赛（赛题一：面向软件多样性的异构变体构造与安全增益验证）的**设计侧仓库**。

基准程序：**Apache httpd 2.4.49**（Linux x86-64，源码零补丁）。

---

## 一句话

用同一条流水线，从 V1（原版）自动生成两个**功能等价、内部不同**的变体 V2/V3；再用同一批攻击打三个版本，证明"同一攻击在不同变体上表现不同"，并把这种不同**量化**出来。

## 核心创新：三个 Agent

| Agent | 职责 | 绝对不做 |
|---|---|---|
| **执行** | 调工具：生成规格、构建变体、编排打靶 | 不判结果、不碰源码 |
| **监管** | 采集证据 + 守 7 条红线 + 阶段闸门 | 不当裁判、不改指标 |
| **评估** | 资格判定、指标计算、可信度自检、出结论 | 不自己造数 |

**判权归机器**：单次试验的 `L0–L3`、根因状态 `P/S/X/U`、等价门 `EQ`，全部由写死的规则判定；agent 只在争议样本（`U_disputed`）上给建议，须人签字才计入。

**主干是调度器代码**：监管 Agent 是副驾，掉线/断网时流水线照跑，只是没人守协议、没人救火。

## 两条异构轴

| 变体 | 轴 | 内容 |
|---|---|---|
| **V2** | 运行形态 | 编译器（gcc/clang）× 优化（O0/O2）× 分配器（ptmalloc/jemalloc）× MPM（event/prefork/worker） |
| **V3** | 权限与攻击链 | 独立低权 UID、敏感面 root-only、UDS 目录收口、CGI 执行身份降级 |

**不修改一行源码**——避开赛题 P020/P021（"针对已知漏洞改源码"）的红线。
V3 是**预注册配方**（i1/i2），不参与 fitness 打分；fitness 搜索只用于 V2。

## 两条度量轨道

- **轨道 A**：`DIV / HDE / ATTR`——分化有多大、其中多少能稳定归因于变体身份；
- **轨道 B**：相对同构基线 `B0={V1,V1,V1}` 的 `ΔASR / ΔCMR / ΔT / 链阻断 / 可用性损失`。

结论一律用 `Δ` 表述：**没有基线就没有"增益"**。
