## v2 与 v1 的差别

v1 的主要问题是偏离了比赛文档：把 **LLM 监管 Agent** 写成可选、把 **可复现性熵** 写成"不能替代安全增益"，并丢失了类型分派、互补性筛选、原语指纹、拟态网关/多阶段攻击链。

v2 恢复为：

- **核心创新一**：LLM 监管 Agent，执行/监管/裁决三层，五项值守，L1/L2 处置，journal 留痕；
- **核心创新二**：可复现性熵 H(i)，K×m 实验，三态互斥映射，与迁移率联合解读；
- **支撑机制**：类型分派异构、互补性筛选、原语级指纹、Evidence-as-Code、多阶段攻击链/拟态网关；
- **两条轨道**：熵实验（配置恒定）与作品变体（可含重构/收敛）统计口径分开。

## 事实边界

V2/V3 未构建，功能门与互补筛选未实现，三版本矩阵未运行，监管 Agent 未实现，熵无任何数值，网关与攻击链未建。任何"已提升安全""抑制率 X%""熵为 Y"的说法在 M5 完成前都不成立。
