## 3. ★核心创新：三 Agent 协同（本文档重点）

> **全文唯一的"核心创新"就是这一章。** 第 4、5 章是它的尺子和产物，不要写成并列的三个创新点。
> 本节占全文篇幅的 **50% 以上**。评委的 20 分创新性主要看这里。

### 3.1 为什么是三个，不是一个或两个

| 方案 | 谁干什么 | 致命问题 |
|---|---|---|
| 单 Agent | 一个模型包办生成、跑实验、判分 | 自己观测自己评分；目标函数在被优化者手里 |
| 双 Agent | 生成 + 监测（兼判分） | 监测既采数据又判分，边界不清 |
| **三 Agent（本文）** | 执行 / 监管 / 评估 | 【待填：一句话说清为什么这个划分是"最小完备"的】 |
